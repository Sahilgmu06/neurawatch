# NeuraWatch

## Real-Time Intelligent Resource Monitoring System for AI/ML Pipelines

NeuraWatch is a full-stack web-based monitoring platform designed to help administrators monitor AI/ML infrastructure resources and system health through a centralized monitoring interface.

The system collects system telemetry, stores monitoring data, provides real-time resource updates, records monitoring events, and presents historical analytics through a responsive web application.

##  Project Objective

The objective of NeuraWatch is to develop a scalable monitoring platform that continuously collects, processes, stores, and visualizes system metrics generated by AI/ML applications.

The platform helps administrators monitor:

- CPU utilization
- Memory utilization
- Disk utilization
- Network activity
- System uptime
- Server status
- Resource threshold violations
- Historical resource usage
- Monitoring events
- Analytics

- Centralized system monitoring interface
- CPU utilization
- Memory utilization
- Disk utilization
- System status
- Uptime information
- Responsive interface

###  Resource Monitoring

NeuraWatch monitors important system resources:

- CPU
- RAM / Memory
- Disk
- Network
- System Uptime

System-level metrics are collected using the `systeminformation` package.

###  Real-Time Monitoring

Real-time resource updates are implemented using **Socket.IO**.

The backend periodically collects current system metrics and broadcasts updates to connected clients.

```text
System Resources
       ↓
systeminformation
       ↓
Node.js Backend
       ↓
